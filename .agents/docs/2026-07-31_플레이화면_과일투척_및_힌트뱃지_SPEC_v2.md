# 📋 [SPEC v2] 플레이 화면 인터랙티브 과일 투척 & 포트레이트 힌트 뱃지 기획서

## 1. 개요 및 변경 반영사항 (v2)
- **적용 범위**: 대기실 제외 ➔ **오직 게임 플레이 화면(`screen === "play"`)에서만 동작**.
- **시스템 메시지 제거**: 텍스트 채팅창 알림 없이 **오직 화려하고 직관적인 시각적 궤적/스플래시 연출만 구동**.
- **에셋 연동**: 커스텀 외부 이미지 대신 **100% 고화질 이모지(🍅, 🥚, 💦, 🍌) + CSS 3D 키프레임**으로 세련되게 연출.

---

## 2. 주요 기능 세부 명세

### 💡 [기능 1] 포트레이트 마우스 호버(Hover) & 힌트 뱃지 인터랙션
1. **마우스 호버 연출**: 플레이 화면에서 상대방 캐릭터 포트레이트 마우스 호버 시, 포트레이트 **좌측 상단에 앙증맞은 `💡 Hint` 뱃지**가 스르륵 노출됨.
2. **`💡 Hint` 뱃지 클릭**: 클릭 시 해당 유저가 라운드별로 작성한 **[힌트 기록 보기] 모달 팝업** 오픈.
3. **포트레이트 본체 영역 클릭**: `💡 Hint` 뱃지 외의 포트레이트 본체 클릭 시 **[과일 투척 휠 팝업]**이 열려 던질 아이템을 바로 선택 가능.

---

### 🍅 [기능 2] 과일/아이템 3D 궤적 투척 & 충돌 시 던진 사람 표식 연출
1. **투척 아이템 4종**:
   - 🍅 **토마토 스플래시**: 붉은 즙이 팡 터지는 연출
   - 🥚 **달걀 팍!**: 톡 깨지며 노란 노른자가 흐르는 연출
   - 💦 **물풍선 팡!**: 콰광 터지며 물방울 스플래시
   - 🍌 **바나나 껍질**: 3회전 미끄러지는 연출

2. **날아가는 3D 곡선 궤적 (Projectile Animation)**:
   - 내 캐릭터 위치에서 대상 캐릭터 위치로 **0.7초간 곡선을 그리며 붕 날아감**.

3. **충돌 시(Hit Point) 던진 사람 표식 팝업 (시스템 메시지 대체)**:
   - 과일이 캐릭터 머리에 맞는 순간, 팡 터지는 파동과 함께 **"누가 던졌는지" (예: `🎯 던진 사람: 🦊 모카`)** 표식이 1.2초간 머리 위에 떠올랐다 스르륵 소멸함!
