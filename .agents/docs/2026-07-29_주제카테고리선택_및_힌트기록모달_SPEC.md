## 🎯 개요

1. **주제 카테고리 선택 기능**:
   - 기존 `server/words.js`에 정의된 15개 이상의 다양한 카테고리(음식, 동물, 영화, 직업, 장소, 과일, 스포츠, 전자제품 등) 목록을 추출.
   - 대기실에서 방장이 **"🎲 전체 무작위"** 또는 **특정 주제(예: 🍔 음식, 🦁 동물 등)**를 직접 선택할 수 있도록 방 설정 확장.

2. **포트레이트 클릭 시 힌트 기록 팝업 모달**:
   - 힌트 발표 턴(`hint-turn`) 동안 각 플레이어가 한 마디로 제출한 힌트를 서버 및 클라이언트(`playerHints[socketId]`)에 라운드별(1R 힌트, 2R 힌트)로 축적 기록.
   - 게임 중 플레이어 프로필/포트레이트를 클릭하면 해당 플레이어가 지금까지 말한 **힌트 히스토리 카드 모달**을 전면에 노출하여 라이어를 추리하기 쉽도록 지원.

## 🛠️ 상세 구현 로직

### 1) 백엔드 카테고리 및 힌트 기록 구조
- `server/words.js`: `getCategories()` 함수 추가 (카테고리 목록 리턴)
- `server/index.js`:
  - `room.selectedCategory`: 방장이 선택한 주제 (기본값 `"ALL"`: 전체 무작위)
  - `room.playerHints`: `{ [socketId]: Array<{ round: number, text: string, time: string }> }` 힌트 기록 맵
  - `start-game`: `selectedCategory`에 맞게 `getRandomWord(selectedCategory)` 선출.
  - `send-chat` 또는 `submit-hint`: 힌트 턴 중 발언한 메시지를 `playerHints`에 라운드별로 보관 후 `room-updated` 또는 `player-hints-updated` 전송.

### 2) 프론트엔드 UI
- **대기실 방 설정 카드**:
  - `📌 제시어 주제` 드롭다운 셀렉트 추가 (`🎲 전체 무작위`, `🍔 음식`, `🦁 동물`, `🎬 영화`, `💼 직업`, `🏖️ 장소` 등)
- **게임 화면 플레이어 포트레이트**:
  - `PlayerChip` 클릭 시 `selectedPlayerHintModal` State를 켜고 힌트 히스토리 팝업 모달 출력.
  - 모달 내용: `[유저 이름]`의 힌트 목록 (1R 힌트: "노란색 과일이에요", 2R 힌트: "달콤해요")
