# 📋 [SPEC] 실시간 핑(Ping) & 인터랙티브 투척(과일/아이템) 시스템 기획서

## 1. 개요 및 기획 배경
- **기획 배경**: 플레이어들이 대기실이나 플레이 화면에서 서로 지목하거나 유쾌하게 소통할 수 있도록, 상대방 캐릭터에게 과일/물건을 던지거나 핑을 찍어 신호를 보내는 **실시간 상호작용 인터랙션(Interactive Emote/Projectile System)**을 도입함.
- **목적**: 게임 대기 시간이나 추리 시간 중 지루함을 없애고 플레이어 간의 유쾌하고 생동감 넘치는 반응형 재미 요소를 극대화함.

---

## 2. 주요 기능 세부 명세

### 🎯 [기능 1] 실시간 핑(Ping) 찍기 시스템
- **동작 방식**: 대기실 및 게임 화면에서 대상 유저의 포트레이트를 클릭하거나 핑 버튼 클릭 시, 해당 플레이어 머리 위에 **보라색/황금색 핑 타겟 파동(Ping Wave)**과 함께 `"🎯 [유저A] 님이 [유저B] 님을 짚었습니다!"` 핑 알림 발동.
- **시각 연출**: 핑 링 파동 펄스 애니메이션 (1.5초 후 깔끔하게 소멸).

### 🍎 [기능 2] 인터랙티브 아이템 투척 (과일/토마토/달걀/하트 등)
- **동작 방식**: 
  1. 상대방 포트레이트를 클릭하면 팝업 휠에 **투척 아이템 메뉴**가 뜸.
  2. 아이템 선택 시 내 캐릭터 위치에서 대상 캐릭터 위치로 **곡선을 그리며 날아가는 궤적(Projectile) 애니메이션** 발동.
  3. 충돌 시 캐릭터 머리 위에서 **펑 터지는(Splash) 이펙트** 및 파편 연출.
- **제공 기본 아이템 종류**:
  - 🍅 **싱싱한 토마토**: 팍 터지며 즙이 퍼지는 연출
  - 🥚 **신선한 달걀**: 톡 깨지며 노란 노른자가 흐르는 연출
  - 💦 **시원한 물풍선**: 팡 터지며 물방울 스플래시
  - 💖 **사랑의 하트**: 샤방샤방 하트 뿅뿅 연출
  - 🍌 **바나나 껍질**: 팽글팽글 미끄러지는 재미 연출

## 3. 필요한 에셋 및 준비 가이드 (사용자 준비 가능 요소)

> [!NOTE]
> 본 기능은 **기본적으로 브라우저 이모지(🍅, 🥚, 💦, 💖)와 CSS 3D/곡선 키프레임 애니메이션만으로 100% 즉시 구현 가능**합니다!
> 다만, 사용자분께서 직접 커스텀 이미지/GIF 에셋을 준비해서 올려주시면 훨씬 고품질의 애니메이션을 연출할 수 있습니다.

### 🎨 추천 준비 에셋 (선택 사항)
1. **투척물 이동용 투명 PNG 이미지** (크기: 64x64 또는 128x128 픽셀)
   - 예: `tomato.png`, `egg.png`, `heart.png`
2. **충돌/파편 터지는 GIF 또는 텍스처 이미지**
   - 예: `splash_effect.gif` (토마토 즙 터지는 GIF), `crack_effect.png` (달걀 깨짐)
3. **에셋 저장 위치**:
   - 준비된 파일은 `src/assets/items/` 폴더에 넣고 에셋 파일명만 알려주시면 바로 연동해 드립니다.
