# 🌐 유료 도메인 구매 및 SSL 보안 배포 가이드 (지인 배포용)

> **작성일:** 2026-07-29  
> **목적:** 개발된 라이어 게임을 유료 도메인과 HTTPS(SSL 보안 인증서)를 적용하여 24시간 지인들에게 실시간 배포하기 위한 가이드

---

## 📌 구조 파악 (왜 배포 설정이 필요한가요?)

라이어 게임은 2가지 요소로 구성되어 있습니다:
1. **프론트엔드 (화면)**: 플레이어들이 접속하는 웹 페이지 (React/Vite)
2. **백엔드 (소켓 서버)**: 24시간 켜져서 실시간 채팅 및 투표를 전달하는 Node.js 서버

---

## 🚀 가장 추천하는 4단계 배포 수순 (초보자 최적화)

### 1단계: 유료 도메인 구매 🛒
- **추천 구매처**:
  - 한국 도메인(`.kr`, `.co.kr`): **가비아 (Gabia)** 또는 **호스팅KR** (연 1~2만 원)
  - 해외 도메인(`.com`, `.xyz`): **Cloudflare Registrar** 또는 **Namecheap**
- 원하는 이름(예: `my-liargame.com`, `liar-party.kr` 등)을 검색하여 결제합니다.

---

### 2단계: 백엔드 소켓 서버 배포 (Render.com 또는 Railway) 🖥️
실시간 소켓 게임이므로 백엔드 서버가 24시간 켜져 있어야 합니다.

- **추천 서비스**: **Render.com** (무료 플랜 지원) 또는 **Railway.app** (월 5$ 내외)
- **혜택**:
  - GitHub 마스터 브랜치와 연동되어 코드 수정 시 **자동 배포**
  - **SSL 보안 인증서(`https://` 및 `wss://`) 자동 무료 발급!**
- **절차**:
  1. 본인 프로젝트를 GitHub에 업로드 (Push)
  2. Render.com 회원가입 ➔ [Web Service] 생성
  3. GitHub 리포지토리 연결 ➔ Build Command: `npm install`, Start Command: `npm run server` 입력
  4. 발급된 백엔드 보안 주소 (예: `https://liar-game-backend.onrender.com`) 획득!

---

### 3단계: 프론트엔드 웹사이트 배포 (Vercel) 🎨
- **추천 서비스**: **Vercel.com** (세계 1위 무상 호스팅, 클릭 한 번으로 배포)
- **혜택**:
  - **무료 SSL 자동 처리** (`https://` 지원)
  - 구매한 유료 도메인 연동이 매우 쉬움!
- **절차**:
  1. Vercel.com 접속 ➔ GitHub으로 로그인
  2. `Liar_Game` 리포지토리 선택 ➔ [Deploy] 버튼 클릭!
  3. 완료되면 보안 기본 주소(`https://liar-game.vercel.app`) 생성 완료.

---

### 4단계: 구매한 유료 도메인 연결 🔗
1. **Vercel 설정**:
   - Vercel 프로젝트 ➔ [Settings] ➔ [Domains] ➔ 구매한 도메인(`my-liargame.com`) 입력.
2. **가비아 (도메인 구매처) DNS 설정**:
   - 가비아 My가비아 ➔ [DNS 관리] ➔ CNAME 레코드에 Vercel이 지정해 준 CNAME 주소 입력!
3. **완료!**:
   - 약 5~10분 후 `https://my-liargame.com` 으로 접속 시 지인들이 모바일/PC 어디서나 접속하여 24시간 게임 플레이 가능!

---
