## 1. 플레이어 이탈 조건별 종합 처리 규칙

```
[플레이어 소켓 연결 끊김 / 퇴장 발생]
         │
         ├── 👑 1) 방장(Host) 이탈 시 (대기실 또는 게임 중 무관)
         │     ➔ "👑 방장이 게임을 이탈하였습니다." 전면 모달 표출
         │     ➔ 방 완전 해체(폭파) ➔ 남은 전원 '캐릭터 선택창(character)'으로 이동
         │
         ├── 😈 2) 라이어(Liar) 이탈 시 (게임 진행 중)
         │     ➔ "🚨 라이어가 게임에서 이탈하였습니다." 전면 모달 표출
         │     ➔ 게임 몰수 종료 ➔ 3초 후 남아있는 전원 '대기실(room)'로 이동
         │
         ├── 👥 3) 남은 인원수 2명 미만 (1명 이하) 진입 시
         │     ➔ "📢 플레이어 수가 부족하여 게임이 종료됩니다." 전면 모달 표출
         │     ➔ 게임 몰수 종료 ➔ 3초 후 남아있는 플레이어 '대기실(room)'로 이동
         │
         └── 🏃 4) 일반 시민(Citizen) 이탈 시 (인원 2명 이상 유지 시)
               ➔ 포트레이트에 "🔴 이탈됨 (재접속 대기)" 표기 및 흑백 반투명 스타일
               ➔ 방장이 설정한 이탈자 대기시간(30초/60초/90초/120초) 내 재접속 시 복구 참전
```

## 2. ⏱️ 방장의 이탈자 재접속 대기시간 설정 기능 (신규 추가)

### 1) 대기실 UI 설정
- 대기실 `ROUND SETTINGS` 패널에 **[⏱️ 이탈 대기시간]** 옵션 셀렉트 추가:
  - 선택 옵션: **`30초` | `60초` (기본값) | `90초` | `120초`**
- 방장이 변경 시 소켓 `update-room-settings` 전송 및 방 안의 모든 참가자 동기화.

### 2) 동작 로직
- 시민 플레이어 이탈 시, 방에서 설정된 `reconnectWaitTime`(예: 60초)을 기반으로 타이머 작동.
- 해당 시간 내 재접속 시 기존 세션(비밀 제시어 등) 그대로 복구 참전.
- 설정 시간 초과 시 방에서 영구 삭제(퇴장) 처리.

## 3. 🔒 테스트 버전 관리자 방 생성 제한 기능 (비밀번호: `0307`)

1. **방 만들기 클릭 시 모달 표출**:
   - 화면에서 **[방 만들기]** 버튼을 클릭하면 팝업 모달이 노출됩니다.
   - 문구: **`테스트 버전이므로 관리자만 방을 생성할 수 있습니다.`**
2. **관리자 비밀번호 검증**:
   - 비밀번호 입력창에 **`0307`** 입력 후 제출해야 방이 생성되어 대기실로 진입합니다.
   - 틀린 경우 **`⚠️ 관리자 비밀번호가 올바르지 않습니다.`** 경고 메시지가 뜨며 생성이 방지됩니다.

## 4. 백엔드 & 프론트엔드 작업 포인트

### 백엔드 (`server/index.js`)
- 방 설정 객체에 `reconnectWaitTime: Number` (기본 60초) 추가.
- `disconnect` 발생 시 방장 이탈 / 라이어 이탈 / 인원 2명 미만 / 시민 이탈(방장 설정 시간 타이머) 분기.
- `create-room` 관리자 비밀번호 `0307` 검증.

### 프론트엔드 (`App.tsx`)
- 대기실 `ROUND SETTINGS` 패널에 `⏱️ 이탈 대기시간` 셀렉트박스 추가.
- 방 만들기 모달 `0307` 입력 검증.
- `host-left-game`, `liar-left-game`, `not-enough-players` 이벤트별 전면 팝업 및 이동 처리.
